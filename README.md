# Tetris (Unity)

Простой тетрис на Unity 2022.3 / Unity 6. Сцена и все объекты создаются при нажатии **Play** — отдельно расставлять префабы не нужно.

## Как запустить

1. Установите [Unity Hub](https://unity.com/download) и редактор **Unity 2022.3 LTS** или новее.
2. В Hub выберите **Open → Add project from disk** и укажите эту папку.
3. Дождитесь импорта пакетов и нажмите **Play**.

## Управление

| Клавиша | Действие |
| --- | --- |
| ← → / A D | Движение |
| ↓ / S | Ускорить падение |
| ↑ / W / X | Поворот по часовой |
| Z / Ctrl | Поворот против часовой |
| Пробел | Сброс вниз |
| P / Esc | Пауза |
| R / Enter | Заново |

## Что внутри

- Семь фигур (I, O, T, S, Z, J, L) и генерация «мешком» из семи
- Призрачная проекция, следующая фигура, очистка линий
- Счёт, уровни (каждые 10 линий) и ускорение падения
- Пауза, game over и кнопка перезапуска

Основные скрипты лежат в `Assets/Tetris/Scripts/`.
