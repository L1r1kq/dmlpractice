# Тетрис

Три версии одной игры: браузер (HTML/JS), консоль (C#) и Unity.

## Браузер — HTML и JavaScript

Не нужен Unity. Дважды откройте файл:

`web/index.html`

Или из терминала:

```sh
open web/index.html
```

## Консоль — C#

Нужен .NET 9 (`dotnet --version`). Затем:

```sh
cd csharp
dotnet run
```

## Unity

Откройте эту папку в Unity Hub (Unity 6). На Mac сейчас может не хватать места под редактор — в этом случае играйте в браузерную или консольную версию.

## Управление

| Клавиша | Действие |
| --- | --- |
| ← → / A D | Движение |
| ↓ / S | Ускорить |
| ↑ / W / X | Поворот |
| Z | Против часовой |
| Пробел | Сброс вниз |
| P / Esc | Пауза |
| R / Enter | Заново |
